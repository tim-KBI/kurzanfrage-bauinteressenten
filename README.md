# Kurzanfrage für Bauinteressenten

Schlankes Kontaktformular für die erste Anfrage: Kontaktdaten, Grundstücksfrage, Herkunft, Bauvorhaben-Auswahl (Mehrfachauswahl möglich) und Datenschutz-Zustimmung – ohne die vertiefenden Detailfragen des ausführlichen [Fragenkatalogs](https://github.com/tim-KBI/fragenkatalog-bauinteressenten).

Anfragen werden über [Web3Forms](https://web3forms.com) kostenlos direkt per E-Mail an Systema Bau übermittelt (systema-bau@t-online.de) – derselbe Zugangsschlüssel wie im ausführlichen Fragenkatalog.

## Hosting

Eigenständiges Vercel-Projekt, unabhängig vom ausführlichen Fragenkatalog, damit beide parallel und unter eigenem Link nutzbar sind.
